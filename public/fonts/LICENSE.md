# Fonts

Fraunces, DM Sans and DM Mono are licensed under the SIL Open Font License 1.1,
which permits bundling and serving the files with this site.

- Fraunces: https://github.com/undercasetype/Fraunces
- DM Sans and DM Mono: https://github.com/googlefonts/dm-fonts

Only the latin subset is bundled. These files were taken from the Google Fonts
CDN and are served from this site instead, so that building it needs no network
access and so that a reader's browser makes no request to a third party.
